# 합격 시험

계약서의 A1~A6을 실행 절차와 기대 결과로 나눈 문서입니다.
ID는 바꾸지 않습니다. 시험을 늘려야 하면 계약서를 먼저 고칩니다.

| 번호 | 실행 절차 | 기대 결과 |
|---|---|---|
| A1 | 제목과 담당자를 입력하고 등록합니다 | 새 요청이 목록에 한 번 나타납니다 |
| A2 | 목록의 한 항목에서 상태를 `완료`로 바꿉니다 | 같은 항목의 상태 표시만 바뀌고 다른 항목은 그대로입니다 |
| A3 | 브라우저를 새로 고칩니다 | 등록한 요청과 바꾼 상태가 그대로 보입니다 |
| A4 | 제목을 비우고 등록합니다 | 저장되지 않고 안내 문구가 보입니다 |
| A5 | 가로 375px로 좁혀서 엽니다 | 가로 스크롤 없이 주요 항목이 보입니다 |
| A6 | 등록·상태 변경·새로 고침을 각각 해 봅니다 | 세 경우 모두 고정 문구 두 개가 화면에 남아 있습니다 |

고정 문구 두 개는 `업무 요청 정리판`과 `이 브라우저에만 저장됩니다`입니다.

## A5의 하위 시험

SECTION 21에서 다음 다섯 항목을 A5 아래에 붙입니다. 최상위 시험 ID는 여섯 개 그대로 둡니다.

- AX1: Tab 키로 제목, 담당자, 상태, 등록 버튼에 이동한다.
- AX2: Enter 키로 등록하고 성공 문구를 확인한다.
- AX3: 오류 문구가 텍스트로 표시된다.
- AX4: 200% 확대에서 핵심 기능을 사용할 수 있다.
- AX5: 색을 보지 않아도 상태 이름을 읽을 수 있다.

## 기록 방법

- 시험마다 PASS 또는 FAIL, 확인 시각, 사용한 브라우저를 적습니다.
- 실패한 시험은 FAIL로 먼저 남기고, 고친 뒤 같은 번호 아래에 재시험 결과를 덧붙입니다.
- 처음 실패한 기록은 지우지 않습니다.
