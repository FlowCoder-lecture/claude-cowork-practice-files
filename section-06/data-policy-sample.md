# 연습용 데이터·보안 정책

실제 회사 정책을 확인하기 어려울 때 이 문서를 대신 사용합니다.
실제 업무로 옮길 때는 반드시 소속 조직의 정책으로 바꿔야 합니다.

## 데이터

1. 실습에는 공개 자료와 가상의 값만 사용한다.
2. 이름, 이메일 주소, 전화번호, 계좌 번호는 입력하지 않는다.
3. 실습 파일은 실습 폴더 밖으로 옮기지 않는다.
4. 실습 복사본은 실습을 마친 날부터 30일 안에 지운다.
5. 화면을 캡처하기 전에 계정 이름과 최근 대화 목록을 가린다.

## 권한

6. 수집 단계에는 읽기 권한만 허용한다.
7. 삭제, 발송, 게시, 결제 권한은 연결하지 않는다.
8. 권한을 넓혀야 하면 실행을 멈추고 승인을 먼저 받는다.
9. 개인 계정으로 우회해 연결하지 않는다.

## 연결 후보 서비스 목록

| 서비스 | 이 실습에서 읽을 것 | 1차 범위 |
|---|---|---|
| 일정 | 오늘 일정 | 포함 |
| 메일 | 답장이 필요한 메일 | 포함 |
| 메시지 | 나를 언급한 글 | 포함 |
| 할 일 | 오늘·내일 마감 | 포함 |
| 파일 저장소 | 없음 | 제외 |
| 결제 | 없음 | 제외 |

## 문의

- 연결이 막히면 조직의 계정 관리 담당자에게 확인한다.
- 담당자를 알 수 없으면 연결하지 않고 샘플 데이터로 실습을 이어 간다.
