# 미니 에이전트 계약서

- 작성 날짜: 2026-07-20
- 검토자: 자가 검토
- 계약 버전: v1

## 1. 정하기: 한 문장의 완료 기준

mini-agent/inbox.txt의 요청 네 건을 읽고 긴급·이번 주·보류 세 범주에 한 번씩 배치한 today-requests-v1.md를 만든다.

## 2. 쪼개기

1. inbox.txt를 읽는다.
2. 각 줄에서 날짜 표현을 찾는다.
3. 긴급·이번 주·보류 중 하나로 분류한다.
4. 입력 항목 수와 출력 항목 수를 확인한다.
5. 새 파일로 저장한다.

## 3. 만들기

- 샘플 입력: mini-agent/inbox.txt (네 줄)
- 출력 파일: mini-agent/today-requests-v1.md
- 필수 제목: `# 오늘 받은 요청`, `## 긴급`, `## 이번 주`, `## 보류`

## 4. 확인하기: 통과 기준 세 개

- 입력 항목 수와 출력 항목 수가 각각 4다.
- 중복 항목 수와 누락 항목 수가 각각 0이다.
- 필수 하위 제목 세 개가 항목이 없어도 모두 남아 있다.

## 5. 돌리기

- 첫 실행은 사람이 수동으로 한다.
- 같은 입력으로 다시 실행하면 기존 결과를 덮어쓰지 않고 today-requests-v2.md를 새로 만든다.
- 입력 파일을 읽지 못하면 결과 파일을 만들지 않고 중단한다.
- 입력 항목이 0건이면 `처리할 요청 없음`이라고만 적은 결과 파일을 만든다. 이 상태는 수집 실패와 구분해 적는다.

## 안전 규칙

- 원본을 수정하지 않는다.
- 결과는 새 파일로 만든다.
- 입력을 읽지 못하면 중단한다.
- 외부 전송은 하지 않는다.

## 이번 버전에서 하지 않는 일

- 할 일 서비스 등록
- 답장 발송
- 원본 파일 정리와 삭제

## 버전 규칙

- 결과 파일 이름은 v1로 시작한다.
- 완료 기준이나 통과 기준을 바꾸면 계약 버전을 v2로 올리고 결과 파일도 v2로 저장한다.
- 실행 횟수만 늘었다면 파일 이름에 날짜를 붙인다.
