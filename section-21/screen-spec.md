# screen-spec.md

## 화면의 목적
요청 한 건을 등록하고 현재 상태를 확인한다.

## 읽는 순서
1. 서비스 이름과 저장 범위
2. 요청 입력 폼
3. 입력 결과 안내
4. 요청 건수와 목록

## 입력 요소
- title: 필수, 최대 80자
- owner: 선택, 비면 `미지정`
- status: 필수, 기본값 `대기`
- submit: `요청 등록`이라는 동작 이름 사용

## 목록 항목
- 제목을 첫 줄에 표시
- 담당자와 상태를 둘째 줄에 표시
- 등록 시각은 보조 정보로 표시
- 상태 변경은 항목 안에서 수행

## 상태 문구
- 빈 목록: 등록된 요청이 없습니다.
- 빈 제목: 요청 제목을 입력하세요.
- 등록 성공: 요청을 등록했습니다.
- 저장 실패: 저장하지 못했습니다. 다시 시도하세요.

## 반응형 기준
- 768px 이상: 입력 요소를 한 줄에 배치
- 767px 이하: 입력 요소를 세로로 배치
- 375px: 가로 스크롤 없이 등록 가능

## 텍스트 와이어프레임

```
+------------------------------------+
| 업무 요청 정리판                    |
| 이 브라우저에만 저장됩니다          |
+------------------------------------+
| 요청 제목 [              ]          |
| 담당자   [        ] 상태 [대기 v]   |
|                         [등록]      |
+------------------------------------+
| 요청 3건                            |
| 제목       담당자       상태        |
| 샘플 요청  민지         진행        |
+------------------------------------+
```

## 데이터 항목

| 항목 | 형식 | 규칙 |
|---|---|---|
| id | 문자열 | 항목을 구분하는 값 |
| title | 문자열 | 비어 있으면 저장하지 않음 |
| owner | 문자열 | 비어 있으면 `미지정`으로 표시 |
| status | 문자열 | `대기`, `진행`, `완료` 중 하나 |
| createdAt | 날짜·시각 | 등록 순서를 확인하는 값 |

## 네 가지 화면 상태

1. 초기 상태: 입력칸이 빈 상태, "등록된 요청이 없습니다" 표시
2. 입력 오류: 제목 아래에 "요청 제목을 입력하세요" 표시
3. 등록 성공: 새 항목이 목록 맨 위에 한 번 표시
4. 저장 복원: 새로 고침 뒤에도 같은 항목과 상태 유지

## 상태 전이표

| 현재 상태 | 사용자 행동 | 다음 상태 | 화면 증거 |
|---|---|---|---|
| 초기 | 정상 입력 후 등록 | 등록 성공 | 목록 첫 항목과 성공 문구 |
| 초기 | 빈 제목으로 등록 | 입력 오류 | 제목 오류와 포커스 |
| 등록 성공 | 상태를 완료로 선택 | 상태 변경 | 같은 카드의 `완료` 문구 |
| 상태 변경 | 새로 고침 | 저장 복원 | 같은 항목과 상태 |
| 저장 복원 | 새 요청 등록 | 등록 성공 | 새 항목이 맨 위에 표시 |

## 합격 시험과 화면 요소 연결

| 계약 시험 | 확인할 화면 요소 |
|---|---|
| A1 | 등록 버튼과 목록의 첫 항목 |
| A2 | 각 항목의 상태 선택 영역 |
| A3 | 새로 고침 뒤 목록 |
| A4 | 제목 입력칸 아래 오류 문구 |
| A5 | 좁은 화면에서 입력 영역과 목록 |
| A6 | 서비스 이름과 저장 범위 안내가 늘 보이는 고정 영역 |

## 키보드 흐름

```
제목 → 담당자 → 상태 → 요청 등록 → 목록 첫 항목
```

- 오류가 나면 흐름은 제목으로 돌아간다.
- 상태 변경 뒤에는 같은 카드의 선택 요소에 포커스를 유지한다.
- 시각적 배치와 키보드 순서가 다르면 HTML 구조를 먼저 고친다.

## 접근성 하위 시험 (A5 아래)

- AX1: Tab 키로 제목, 담당자, 상태, 등록 버튼에 이동한다.
- AX2: Enter 키로 등록하고 성공 문구를 확인한다.
- AX3: 오류 문구가 텍스트로 표시된다.
- AX4: 200% 확대에서 핵심 기능을 사용할 수 있다.
- AX5: 색을 보지 않아도 상태 이름을 읽을 수 있다.
