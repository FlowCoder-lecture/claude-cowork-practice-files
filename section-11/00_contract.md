# 업무 동향 노트 계약

- 주제: AI 업무 도구·정책 동향
- 입력: 공식 자료 3건 이상
- 기간 기준일: 2026-07-20 (대상 기간 2026-07-14 ~ 2026-07-20)
- 결과: 1,200자 안팎의 Markdown 노트
  (계산 기준: 공백 제외, front matter·주석·URL·참조 태그·마크다운 기호 제외, ±20% 허용)
- 필수 구성: 제목, 핵심 변화 3개, 업무 영향, 출처 링크
- 금지: 근거 없는 수치, 출처 없는 단정, 자동 외부 게시
- 검토자: 사람
- 완료 시각: 2026-07-24 16:00 Asia/Seoul
- 완료 위치: work_pipeline/04_publish/final.md
- contract_owner: 본인
- next_review_date: 2026-08-21
- active_version: 1
- superseded_versions: []

## 하지 않을 일

- 유료 자료를 우회해 읽지 않는다.
- 확인하지 않은 수치를 만들지 않는다.
- 사람의 승인 없이 외부 채널에 게시하지 않는다.

## Boundary rules

- 유효 자료 0~2건: BLOCKED
- 유효 자료 3~8건: READY
- 유효 자료 9건 이상: 중복 제거 후 중요도 기준으로 8건까지 사용
- 접근 실패 1건 이상: 실패 자료가 핵심인지 사람 확인

## 이 파일을 본인 업무로 옮길 때

`주제`는 연습용 예시 값입니다. 본인 업무로 옮길 때 반드시 바꿔 적습니다.
`기간 기준일`과 `완료 시각`도 실제 실행일에 맞춰 날짜로 다시 적습니다.
