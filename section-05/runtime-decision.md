# runtime-decision.md

## 1. 입력의 위치

| 입력 | 위치 |
|---|---|
| mini-agent/inbox.txt | 로컬 파일 |
| 분류 기준(agent-contract-mini.md) | 로컬 파일 |
| 연결된 서비스 | 사용하지 않음 |
| 공개 웹 | 사용하지 않음 |
| 클라우드 저장소 | 사용하지 않음 |

## 2. 결과가 필요한 마감 시각

- 평일 18:00
- 허용 지연: 2시간
- 놓쳤을 때: 다음 날 실행을 기다리지 않고 사람이 그날 안에 한 번 수동 실행

## 3. 사람 승인이 필요한 단계

- 결과 검토: 누락과 잘못된 긴급 표시를 사람이 확인한 뒤에만 할 일 목록에 반영

## 4. 필요한 권한 범위

- 읽기: mini-agent 폴더
- 쓰기: mini-agent 폴더 안의 새 파일 생성만
- 삭제, 덮어쓰기, 외부 전송: 없음

## 기본 실행 장소

로컬

## 선택 이유

입력이 mini-agent 폴더의 로컬 파일 한 개뿐입니다.
사람이 실행 직후 결과를 확인하고 규칙 한 줄을 고치는 단계입니다.
정해진 시각을 반드시 지켜야 하는 조건이 아직 없습니다.

## 실패 신호

- today-requests-v1.md가 생기지 않음
- 결과의 항목 수가 4가 아님
- inbox.txt의 수정 시각이 실행 전후로 달라짐

## 재실행 방법

- 원인을 check-v1.md에 한 줄로 적는다.
- 규칙이나 입력 가운데 하나만 고친다.
- 사람이 같은 폴더에서 한 번만 다시 실행한다. 자동 재시도는 하지 않는다.

## 대체 장소 또는 수동 절차

- 컴퓨터를 쓸 수 없을 때: 요청 목록을 대화 화면에 붙여 넣고 결과만 받은 뒤, 파일 저장은 컴퓨터에서 한다.
- 실패했다고 해서 권한을 넓히거나 다른 폴더를 자동으로 찾지 않는다.
