# 반복 업무 카드

## 선택한 이유

평일 오후 4시라는 분명한 시작 신호가 있고, 입력(그날 받은 요청)과 결과(세 묶음 분류)가 매일 같은 형태로 반복된다.
분류 결과는 누락과 잘못된 긴급 표시만 확인하면 사람이 바로 검토할 수 있고, 원본 요청은 그대로 남아 있어 틀려도 다시 할 수 있다.
외부 전송·삭제·결제가 없고 요청 목록 한 건으로 30분 안에 시험해 볼 수 있어 첫 후보로 가장 적합하다.

## 항목

- 업무 이름: 받은 요청 정리
- 시작 신호: 평일 오후 4시
- 입력: 그날 받은 요청 목록
- 결과: 긴급·이번 주·보류 세 묶음
- 사람이 확인할 항목: 누락된 요청, 잘못된 긴급 표시
- 확인 뒤 사용할 곳: 할 일 목록

## 두 줄 형식

평일 오후 4시가 되면 그날 받은 요청 목록을 읽고 긴급·이번 주·보류 세 묶음을 만든다.
사람이 누락된 요청과 잘못된 긴급 표시를 확인한 뒤 할 일 목록에 반영한다.

## 첫 카드에서 제외한 행동

- 외부 전송
- 원본 삭제와 이름 변경
- 결제와 환불 승인
