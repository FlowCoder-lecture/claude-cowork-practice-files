# 사례: 제휴 요청 검토의 반복 업무 카드

| 항목 | 내용 |
|---|---|
| 업무 이름 | 익명화한 제휴 요청 다섯 건을 검토 순서대로 배열하기 |
| 시작 신호 | 매주 금요일 오후 3시 |
| 입력 | 메일·소개 메시지·행사 신청서로 들어온 제휴 요청 중 익명화한 다섯 건 |
| 결과 | `partnership-review.md`: 다섯 건을 검토 순서대로 배열하고, 건마다 해당하는 분류 표시를 붙인 파일 |
| 사람이 확인할 항목 | 금액과 계약 조건. 자동화는 판단하지 않고 '사람 검토' 표시만 붙임 |
| 자동화하지 않는 일 | 답장 발송, 금액 결정, 일정 확정 |

분류 기준은 표의 여섯 항목에 자리가 없어서 따로 적었습니다.

| 조건 | 표시 |
|---|---|
| 일정이 2주 안 | 먼저 확인 |
| 제안 내용과 희망 결과가 모두 있음 | 자료 충분 |
| 금액·계약 조건이 나옴 | 사람 검토 (판단하지 않음) |

아직 정해지지 않은 것이 두 가지 있습니다.
- **표시 사이의 순서**: 한 건에 표시가 여러 개 붙거나 하나도 안 붙을 때 무엇을 앞에 둘지 기준이 없습니다.
- **'2주 안'의 기준일**: 금요일 실행일부터 세는지, 요청이 들어온 날부터 세는지 정해야 합니다.
