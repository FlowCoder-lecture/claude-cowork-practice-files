# 작업 배치표

접근할 폴더: mini-agent

| 순서 | 작업 | 종류 | 추천 표면 | 필요한 권한 | 사람이 승인할 지점 |
|---|---|---|---|---|---|
| 1 | 분류 기준 정하기 | 생각 | Chat | 입력한 텍스트 | 기준 확정 |
| 2 | 요청 목록 읽기 | 실행 | Cowork | 실습 폴더 읽기 | 폴더 선택 |
| 3 | 세 묶음 만들기 | 실행 | Cowork | 새 파일 생성 | 결과 검토 |
| 4 | 형식 검사 자동화 | 구축 | Code | 프로젝트 폴더 | 테스트 확인 |

## 메모

- 4번은 같은 형식 검사를 세 번 이상 반복하게 될 때만 만든다. 첫 바퀴에서 필요하지 않다면 이 행은 지운다.
- 삭제, 덮어쓰기, 외부 전송은 자동 승인하지 않는다.
- 표면을 바꾸더라도 입력 파일 이름과 결과 파일 이름은 그대로 둔다.
