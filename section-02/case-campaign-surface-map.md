## 캠페인 회고 문서 작업 배치표

| 순서 | 작업 | 종류 | 맡길 곳 | 배치 이유 | 대체 방법 |
|---|---|---|---|---|---|
| 1 | 회고 목적, 비교 기준, 회고 질문 정리 | 생각 | 대화 | 파일을 열지 않아도 목표와 비교 기준을 정리할 수 있습니다. | 폴더 연결: 기존 회고 양식을 함께 보며 질문을 다듬습니다. |
| 2 | 광고 결과 CSV, 고객 반응 메모, 회고 양식 구조 파악 | 실행 | 폴더 연결 | 열 이름, 기간, 메모 형식은 파일을 직접 읽어야 확인할 수 있습니다. 팀 폴더가 아닌 작업 폴더만 허용합니다. | 대화: CSV 머리글 몇 줄과 양식 항목을 붙여넣어 확인합니다. |
| 3 | 캠페인 한 건의 지표를 손으로 계산하고 계산식 남기기 | 실행 | 폴더 연결 | 도구 없이 계산 과정을 새 파일로 남겨 4번에서 규칙을 정하는 근거로 씁니다. | 대화: 해당 캠페인 행을 붙여넣어 계산합니다. |
| 4 | 지표 이름과 반올림 규칙 확정 | 사람 승인 | 없음 | 이후 모든 계산의 기준이 됩니다. 3번 결과를 광고 매체 수치와 대조해 담당자가 정합니다. | 대체 없음: 담당자가 없으면 대리 승인자가 정합니다. |
| 5 | 고객 반응 메모를 주제별로 분류하고 요약 | 실행 | 폴더 연결 | 메모 파일을 읽어 주제별로 묶고, 원문 인용과 해석을 나눠 새 파일로 남깁니다. | 대화: 메모를 붙여넣어 분류합니다. |
| 6 | 성과와 반응을 엮어 잘된 점, 아쉬운 점, 다음 액션 정리 | 생각 | 폴더 연결 | 3번과 5번 결과 파일을 함께 보며 판단해야 합니다. | 대화: 두 결과의 요약을 붙여넣어 논의합니다. |
| 7 | 기존 양식에 맞춰 회고 문서 초안 작성 | 실행 | 폴더 연결 | 양식을 읽어 작업 폴더에 새 파일로 만들고, 양식 원본은 덮어쓰지 않습니다. | 대화: 양식 항목과 내용을 붙여넣어 본문을 받은 뒤 직접 옮깁니다. |
| 8 | 최종 검토 후 팀 폴더 반영 | 사람 승인 | 없음 | 팀이 함께 보는 결과물이라 자동으로 올리지 않습니다. 숫자와 민감정보를 확인한 뒤 사람이 직접 올립니다. | 대체 없음: 자동 업로드로 바꾸지 않고 사람이 직접 올립니다. |
| 9 | 지표 계산 도구 만들기 (구축 후보) | 구축 | Code | 3번의 한 건 손계산과 4번의 지표 이름·반올림 규칙 확정이 끝난 뒤에만 후보가 됩니다. 만든 뒤에는 3번 결과와 같은 값이 나오는지 확인하고 다음 캠페인부터 씁니다. | 폴더 연결: 확정한 규칙 문서를 주고 캠페인마다 계산을 맡깁니다. |

팀 폴더는 연결하는 폴더에 넣지 않았습니다. 그래서 8번 승인 없이는 팀 폴더에 아무것도 반영되지 않습니다.
