# 사례: 캠페인 회고 작업 배치표

| 순서 | 작업 | 종류 | 추천 표면 | 배치 이유 | 대체 방법 |
|---|---|---|---|---|---|
| 1 | 광고 결과 CSV, 고객 반응 메모, 회고 양식을 작업 폴더에 모으고 빠진 항목 확인 | 실행 | Cowork | 파일 여러 개를 직접 열어 열 이름, 기간, 빈 값을 확인하는 파일 작업 | 파일 세 개를 채팅에 첨부해 확인 요청 |
| 2 | 캠페인 한 건의 지표를 손으로 계산 | 생각 | 채팅 | 어떤 열을 분자와 분모로 쓸지 한 줄씩 따져 보며 정의를 잡는 일 | 스프레드시트에서 직접 계산하고 식만 채팅에서 검토 |
| 3 | 지표 이름과 반올림 규칙 확정 | 사람 승인 | 없음 | 이후 모든 회고의 숫자 기준이 되므로 사람이 정해야 함 | 팀장이나 팀원과 함께 보고 확정 |
| 4 | 고객 반응 메모를 주제별로 분류하고 요약 | 생각 | 채팅 | 메모의 뉘앙스를 읽고, 묶는 기준을 대화로 조정해야 함 | 메모 파일이 많으면 Cowork에서 한꺼번에 읽혀 분류 |
| 5 | 숫자와 고객 반응을 함께 해석해 잘된 점, 아쉬운 점, 다음 액션 도출 | 생각 | 채팅 | 캠페인 배경을 설명하고 반박하며 다듬는 판단 작업 | 6번과 묶어 Cowork에서 초안을 쓰며 함께 진행 |
| 6 | 회고 양식에 내용을 채워 초안을 작업 폴더에 저장 | 실행 | Cowork | 양식 파일을 열어 채우고 새 파일로 저장하는 여러 단계의 파일 작업 | 채팅에서 본문을 받아 양식에 직접 붙여넣기 |
| 7 | 초안의 숫자와 표현을 검토하고 확정 | 사람 승인 | 없음 | 숫자가 원본과 맞는지, 팀에 공유해도 되는 표현인지는 담당자 책임 | 팀원에게 교차 검토 요청 |
| 8 | 확정본을 팀 폴더에 반영 | 사람 승인 | 없음 | 팀 전체가 보는 공간이라 자동 실행하지 않고 사람이 직접 올림 | 팀원이나 팀장이 확인한 뒤 직접 업로드 |
| 9 | 지표 계산 도구 만들기 (구축 후보) | 구축 | Code | 3번에서 지표 이름과 반올림 규칙이 확정된 뒤에만 후보가 됨. 같은 계산을 캠페인마다 반복하므로 규칙을 고정한 도구가 실수를 줄임 | 스프레드시트 수식 템플릿으로 고정하거나 2번 방식의 손계산 유지 |

- **첫 회고와 계산 도구:** 첫 회고는 2번의 손계산 숫자로 만들고, 9번은 그 뒤에 진행합니다. 도구를 만들면 다음 캠페인부터 2번을 대신하며, 첫 결과는 손계산 값과 맞는지 비교해 보세요.
- **팀 폴더:** Cowork는 1번과 6번 모두 작업 폴더 안에서만 움직이고, 팀 폴더에 올리는 일은 8번에서 사람이 직접 합니다.
